# MIDI Synth

With live playback and video generation functionality.

Input is a MIDI file and corresponding TOML config file.
See `songs` for examples.
Run with the stem, e.g. `songs/tri2`.

Use `-p` to print the active notes to the terminal to create a piano waterfall.

Use `-o <out.mp4>` to generate a video with a similar note waterfall.
